# EFactura.Net.Client

.NET client for the ANAF RO e-Factura REST API — upload, status, download, message listing,
validation, XML-to-PDF, OAuth2 helpers and company lookup by CUI.

> Unofficial. Not affiliated with or endorsed by ANAF.

```bash
dotnet add package EFactura.Net.Client
```

Full documentation: https://github.com/andreisamoila74/EFactura.Net
